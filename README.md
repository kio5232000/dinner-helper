# 🍚 今晚煮什麼？ Dinner Helper

孩子今天中午在學校吃什麼，晚餐就換個口味。

## V1.1：午餐優先的手機首頁

- 初次使用只需選擇縣市及輸入學校名稱
- 儲存學校設定（沿用 V1 的瀏覽器 localStorage 設定，不需重新選校）
- 再次開啟網站，第一眼看到日期、學校、今日午餐清單
- 五道菜色以 **餐點 SVG 插畫示意圖** 呈現
- 午餐下方才顯示「AI 推薦今晚煮什麼」按鈕
- 點擊後展開三道不同主要食材的晚餐示範靈感；可查看食材、步驟及換一批
- **取消**家庭人數、預算、烹調時間等設定
- 手機優先，免登入、不需要建置工具

## ⚠️ V1.1 仍是前端展示原型

- 學校名稱目前為自由輸入、只作為顯示標籤，**還沒有接官方學校名冊**。
- 午餐資料為輪替示範菜單，**不是該校今天的實際午餐**。
- 餐點圖片是專案內建 SVG 插畫，不是供餐照片，介面已標註「插畫示意」。
- 「AI 推薦」目前使用本地規則挑選與午餐主要蛋白質不同的家常菜，**尚未串接 OpenAI API**。
- 食譜沒有經過正式人工審核，**不適用於過敏飲食安全決策**。
- 首次選校資料僅儲存在當前瀏覽器；清除網站資料或換裝置需要重設。
